# Project: Art Portfolio & Commission Funnel (V1)

## Tech Stack
- Framework: Astro (Static Site Generation)
- Deployment: GitHub Pages
- Styling: Standard CSS with CSS Variables (to keep it raw, flexible, and true to the early web vibe)
- Forms: Standard HTML forms (ready for a handler like Formspree or Netlify Forms)

## Vibe & Aesthetic
- Style: Early-2000s Y2K web kitsch mixed with Mexican feminine surrealism and subtle eroticism.
- Color Palette: Maximalist. Deep, saturated colors (marigolds, magenta, velvet reds, midnight purple). STRICT RULE: NO stark white backgrounds.
- UI Elements: Custom cursors, thick stylized borders around images, hovering elements, "digital polaroid" or ornate vintage frames for lo-fi image assets.
- UX: Despite the maximalism and kitsch, navigation must remain intuitive and accessible.

## Sitemap & Routing
- `/` (Home): Maximalist portal. Quick intro, routing users to Portfolio or Commissions.
- `/portfolio/murals-and-spaces`: Archive of large-scale immovable works.
- `/portfolio/canvas-and-wood`: Archive of original fixed/movable paintings.
- `/portfolio/objetos`: Small crafts, jewelry, mixed media.
- `/commissions/murals`: B2B funnel for holistic spaces/restaurants.
- `/commissions/bespoke`: B2C funnel for private clients (vision/collaboration).
- `/linaje` (About): Connection to Mexican heritage, surrealist inspiration.
- `/tienda` (Shop): Non-ecommerce waitlist/email capture for future merch (prints/stickers).
- `/contact`: General inquiries.

## V1 Goals
- Primary: Capture commission requests (70%).
- Secondary: Digital business card / portfolio (10%).
- Future: E-commerce (20% - DO NOT implement cart, checkout, or state management in V1).
